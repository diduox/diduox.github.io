[02]BERT论文笔记

2026-03-19
个人博客>学习笔记
2.3k 词
  • 机器学习
  • 深度学习
Abstract

BERT，Bidirectional Encoder Representations from Transformers（来自Transformer的双向编码器表示）。

所有层考虑上下文(Transformer只考虑前面)，使用未标注文本(自监督训练)。

预训练之后只需要添加一个输出层就能微调到适合多个任务。

BERT概念简单，实证有用，吊打所有模型。

Conclusion

丰富的无监督预训练是语言理解系统必不可少的。

BERT的贡献是把上述结论从单向框架推广到多向框架，并且这样的预训练模型在NLP任务上有很强的泛用性。

Introduction

预训练在NLP任务上很有用。

将预训练用在下游任务有两种方法:feature-based和fine-tuning。

feature-based是ELMo在用，fine-tuning是GPT在用；但是它们的预训练都是单向(unidirectional)语言模型。

单向的语言模型限制了预训练的能力，这种限制对句子级(sentence-level)任务不好，对使用微调的词元级(token-level)任务有很大危害，因为token-level任务要考虑上下文信息。

BERT改善了基于微调的方法，使用掩码语言模型MLM(Masked Language Model)和下一句预测（Next Sentence Prediction）两个任务进行预训练。

Related Work
1 Unsupervised Feature-based Approaches

预训练的词嵌入(embeddings)很重要,相比从零开始学习嵌入效果更好。

ELMo及其前辈对词嵌入做了推广，也使用左右方向的拼接，但其是基于特征(Feature-based)的，而不是基于深度双向的。

2 Unsupervised Fine-tuning Approaches

从未标注文本中训练词嵌入参数，并在有监督的下游任务进行微调，仅需少量参数就可从零学习。

3 Transfer Learning from Supervised Data

对有监督的大数据任务进行迁移学习。

BERT

BERT的使用有两个步骤pre-training and fine-tuning。

对每个具体任务使用不同的Label Data进行 fine-tuning，生成不同的模型。

BERT的特点：预训练架构和下游任务架构之间的区别特别小。

对于句子对而言，其会被打包到同一序列中，并通过两种方式区分句子。

1.使用特殊token[SEP]将两个句子分开。

2.添加一个学习的embedding到每一个token，来表示其属于哪一个句子。

input = segment embeddings + position embeddings + position embeddings

Pre-training BERT

用了两个任务来pre-train BERT。

[!NOTE]

这两个任务是同时进行的

在一条输入中，MLM 和 NSP 同时训练，共享同一个 Transformer 编码器参数。

任务一：MLM（Masked LM）

即随机Mask输入中一定比例的Token，然后预测这些被Mask的Token。

但是其存在一个问题：预训练和微调之间不一致，因为在微调阶段不会出现[Mask]标记。

所以我们有三种替换方式：80%用[Mask]标记替换，10%用一个随机词替换，10%保持该词不变。

任务二：NSP（Next Sentence Prediction）

对二分类的下一句预测任务进行预训练，选用句子A和句子B。

50% 的情况下，B 是紧跟在 A 后的真实句子;50% 的情况下，B 是语料库中随机选择的一句句子

如图所示，[CLS]对应的向量C就是对应NSP任务。

预训练语料用了BooksCorpus和English Wikipedia。

Fine-tuning BERT

微调非常简单，只需要将任务特定的输入和输出插入BERT，并对所有参数进行端到端的微调即可。

预训练的句子A和句子B举例：

  • 同义转换任务中的句子对
  • 推理任务中的假设-前提对
  • 问答任务中的问题-段落对
  • 文本分类或序列标注中的单句-空对

Token表示处理词级任务，[CLS]处理分类任务。

并且微调非常省资源。

Experiments

简单来说就是BERT在很多任务上表现都很棒，并且写了一些实现在具体任务时的训练参数。

Ablation Studies（消融实验）

消融实验时深度学习和机器学习用的方法，用来研究模型中各个组件对整体性能的贡献。

1 Effect of Pre-training Tasks

总体含义就是BERT比NO NSP 和 LTR + NO NSP表现要好，即使加上一个随机初始化的BiLSTM也是如此。

就是表明双向深度很重要，MLM和NSP任务很重要。

2 Effect of Model Size

更大的模型带来了稳定的准确率提升，即使是现在最大的模型(TransformerLARGE)，使其变得更大(BERTLARGE)性能也会提升。

并且如果较大模型经过了充足的预训练，其在小规模的任务上也会带来显著提升。

3 Feature-based Approach with BERT

BERT其实有两种用法：fine-tuning(微调)和feature-based(特征方法)

微调就是把整个BERT拿过来，然后接一个分类层，再一起训练。

特征方法就是BERT不动，只用其输出的向量，之后再接一个新模型。

因为有些任务不适合Transformer结构，而且为了省算力，所以采用特征方法。

结论是微调最好，特征稍逊一点点。

BERT 不仅可以“整体训练”（fine-tune），也可以“当特征提取器用”，而且效果依然很好。
