[03]GPT论文笔记

2026-03-23
个人博客>学习笔记
2.3k 词
  • 机器学习
  • 深度学习
Abstract

虽然无标签文本语料丰富，但是用与具体任务的有标签语料很少。

用无标签文本预训练模型，之后再使用有标签文本进行微调，效果很好。（这不是就是BERT吗？虽然BERT是后发的论文）

我们这样得出来的模型，比那些专门为任务而设计结构的模型表现得还要好。

Conclusion

GPT通过生成式预训练和判别式微调，使与任务无关的模型有了强大能力以及世界知识，并且能处理长距离依赖。

无监督训练很有前途，使用无监督训练实现显著的性能提升是可能的。

Introduction

从原始文本进行学习对于减轻监督学习的依赖至关重要，此外，即使在有充足监督数据的情况下，使用无监督学习也能显著提升性能。（例如自己学习的Embeddings）

从未标注文本中获得超越词级别的信息有两个挑战：

1.不知道使用什么任务对模型进行预训练。（BERT中是NSP和填空）

2.不知道怎么把训练好的模型迁移到下游任务中。

在GPT中，我们使用半监督方法，先无监督预训练模型，再有监督运用到下游任务上。

GPT用Transformer架构，因为其能记住并利用很远的信息(自注意力机制)，迁移性能好。

结果是GPT表现很好，使用零样本(zero-shot)行为可以证明，模型在预训练阶段已经学到了通用的语言知识。

Related Work
Semi-supervised learning for NLP

最早的无监督学习是用未标注数据的统计信息作为特征(词频，n-gram，PMI)，之后发展到使用Embeddings，但是其只能捕捉word-level的信息。

近期的方法已经开始探索句子级和短语级的Embeddings了。

Unsupervised pre-training

研究表明，预训练可以作为一种正则化手段，从而提升深度神经网络的泛化能力。

在GPT之前，也有使用语言模型先进行预训练的，然后在任务上进行有监督的微调；但是其使用是LSTM，预测能力较短，并且需要为不同的目标引入大量新的参数。

Auxiliary training objectives

添加辅助的无监督训练目标是半监督学习的另一种方式。早期方法通常通过多任务学习或在主任务中引入辅助目标（如词性标注、分块、命名实体识别或语言模型）来提升性能。

虽然GPT把预训练阶段的语言模型目标也看作一种”辅助目标”，但是无监督预训练本身已足够强大。

Framework
Unsupervised pre-training

使用的目标函数是预测下一个Token的条件概率，参数为$\theta$，使用SGD进行训练。

使用Transformer的Decoder作为语言模型。

Supervised fine-tuning

进行完预训练之后，我们将模型参数适配到有监督的目标任务上。

输入为Token序列${x_1,x_2,x_3}$，输出为$y$，传入预训练模型之后，得到Transformer的激活表示$h_l^m$，将其在输入到一个新的线性输出层，再进行SoftMax用来预测$y$。

此外，在微调过程中将语言模型作为一个辅助目标，有助于训练：(1)提升泛化能力(2)加快收敛速度。（即在进行微调时，一起做预训练所作的下文预测）

Task-specific input transformations

对于文本分类这种任务，可以直接进行微调。

但是有些任务（问答，文本蕴含）的输入是结构化的，因为我们预训练在连续的文本序列，所以我们要对其的输入进行改造。

GPT使用遍历式方法（traversal-style），将结构化输入转换为模型可以处理的有序token序列。避免对模型架构进行大量修改。

对于上图的Similarity任务，将输入序列包含两种句子顺序，并分别处理，最后在逐元素相加，输出到线性层里。

对于Multiple Choice任务，我们将相同的上下文和每一个候选答案拼接起来。

Experiments
Setup

使用 BooksCorpus 数据集进行预训练，因为其包含大量连续的长文本，使得生成式模型能学习基于长距离信息进行建模，并且效果很好。

还有能用数据集是 1B Word Benchmark，但是其在句子层面打乱了顺序，破坏了长距离结构。（这是GPT拷打ELMo用的数据集不够好）

GPT的模型基本遵循原始的Transformer，使用Adam优化算法，学习率先从0线性增长，然后使用余弦退火策略逐渐衰减至0。

使用LayerNorm，所以只需要简单的权重初始化；使用BPE(bytepair encoding)词表，使用0.1的Dropout进行正则化。

使用改进版的L2正则化方法，对非偏置项和非偏执参数施加衰减系数$w$=0.01。（除了β和LayerNorm里面以外的$w$）。

使用GLUE激活函数，使用可学习的位置Embeddings，而不是Transformer的正弦函数编码。

对于数据预处理，使用ftfy库进行数据清洗，对文本和标点进行标准化处理，使用spaCy分词器进行分词。

在微调时，除了某些特殊的超参数，都使用预训练时的配置。

Supervised fine-tuning

我还以为会讲什么怎么进行有监督训练微调，结果都是说我们的GPT模型比别人要厉害。

Analysis

无监督预训练迁移到有监督目标任务的层数越多，性能越好。

这表明预训练模型的每一层都包含对解决目标任务有用的功能。

对于与预训练的Transformer为什么如此有效，有两个假设：

1.底层的生成模型在为了提升自己语言建模能力，执行了我们用于评估的许多任务。

2.相比于LSTM，Transformer的更有结构的注意力记忆更有利于迁移。

Transformer的归纳偏置有利于知识迁移。
