5.关于LangSmith

LangSmith 是框架级别的自动注入，不需要你写任何代码。

它的原理是：当 LANGCHAIN_TRACING_V2=true 被设置时，LangChain/LangGraph 内部会自动注册一个 LangChainTracer 回调，拦截所有 LLM 调用、Tool 调用、Agent 节点之间的流转，然后异步上报到 LangSmith。

你的代码
→ create_agent(model=llm, tools=tools)
→ agent.invoke(…)
→ LangChain 内部每一步都触发 callback 钩子
→ LangChainTracer 自动捕获 → 上报 LangSmith
