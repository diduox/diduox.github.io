ISARA-少样本下的无人工指令大模型自我对齐

2026-07-16
NLP>个人博客>学习笔记>留档>论文批判
1.9k 词
  • 低资源学习
  • 大语言模型
  • 检索增强上下文学习
  • 自我对齐

Paper: Human-Instruction-Free LLM Self-Alignment with Limited Samples

1. Meta

  • Year: 2024

  • Venue: arXiv

  • Link: https://arxiv.org/abs/2401.06785

2. One-line takeaway

提出了一种名为 ISARA 的迭代自我对齐算法，仅需极少量（如少于100条）的目标领域种子样本，无需人工编写的指令原则或外部奖励模型，通过检索增强的上下文学习（ICL）与迭代微调，即可解锁小参数大语言模型（如350M、7B）的高质量自我对齐能力 。

3. Problem

当前的大模型对齐技术（如RLHF或SFT）存在显著局限：(1) 需要大量的高质量标注数据；(2) 高度依赖人工参与（如设计复杂的Prompt原则或标注奖励模型）；(3) 缺乏一种能让模型持续自我改进的系统化机制 。 虽然目前也有一些自我对齐（Self-Alignment）的研究，但它们通常仍然需要人工干预（手工设计原则或指令），并且往往只在参数量极大的模型（如65B以上）上有效，在人工资源匮乏的少样本场景及小模型上难以落地 。

4. Module

  • 核心模块1：检索增强的上下文学习（Retrieval-Augmented ICL）：为了生成高质量的训练数据，算法不使用人工预设的规则指令，而是利用外部 Embedding 模型（如 text-embedding-ada-002）进行 k-nearest-neighbors (kNN) 检索，从初始数据集或历史迭代中找出最相似的上下文样例 。模型只需模仿这些高质量检索样本的“风格”即可生成符合目标领域的问答对 。

  • 核心模块2：迭代自我微调（Iterative Enhancement & SFT）：采用多轮迭代机制 。在每一轮中，将最新一轮生成的可靠数据与极少数的初始人工种子数据合并，通过监督微调（SFT）更新 LLM 。对齐能力提升后的 LLM 会在下一轮中生成质量更高的数据，反哺自身的进一步对齐，直到生成的新数据无法通过质量过滤阈值为止 。

  • 核心模块3：基于规则的自动化过滤（Simple Filtering）：无需训练复杂的奖励模型（Reward Model），仅依靠简单的规则筛除劣质样本：(1) 与已有问题的 ROUGE-L 相似度大于等于0.7；(2) 完全重复的问题；(3) 答案仅仅是对问题的复读；(4) 问题或答案词数少于5个词 。

5. Strength / Weakness

  • ✔ Strength:

    • 极低的人工成本：真正实现了“零人工指令”与“无奖励模型”参与，仅凭少于100条的种子 QA 数据即可启动闭环 。
  • 对小模型非常友好：打破了之前自我对齐方法对超大模型指令遵循能力的依赖，在 350M (OPT) 和 7B (LLaMA) 等小模型上均表现优异 。

  • ✖ Weakness:

    • 训练开销叠加：算法的迭代机制（生成数据 -> SFT微调 -> 再生成数据）相比于单次 SFT 或 ICL 推理，会带来多轮的算力时间开销 。
  • 依赖外部 Embedding 模型：在检索增强生成时，仍需要依赖额外的 Embedding 模型来计算句子相似度以执行 kNN 检索 。

6. Notes (optional)

1.首先检索与目标领域相关的高质量样本，将其作为上下文学习示例以生成更多样本；然后利用这些自生成样本对模型进行迭代微调。 这不是被做烂的弱监督吗…….让我再看看有什么我没有注意的创新点。

2.指令微调：让模型学会执行各种自然语言指令。 偏好学习：告诉模型两个答案哪个更好。

3.现有的自我对齐方法虽然能够自动生成数据，但仍然依赖人工设计的原则（Principles）、Prompt 或启发式规则来筛选和评价生成结果，因此整个流程并非真正意义上的全自动。小模型自我对齐能力弱。

4.“检索增强的上下文学习(ICL)”把和训练数据相似的上下文作为few-shot 来使生成的内容变得更好。

5.分为周期训练，每次生成新的训练数据的时候都会使用最新的模型进行。框架甚至可以适配0.35B参数的模型。

9.在微调的时候使用的是原始数据集+新生成数据集 同时使用系数γ来调节各个数据集的用量比例。

10.ISARA通过多轮“生成数据→过滤→微调”不断提升模型能力。 随着模型增强，生成数据质量会提高，但新增高质量样本比例会逐渐下降，因为： - 模型能力趋于饱和； - 新生成数据容易重复； - 可挖掘的新知识有限。 因此，当过滤后保留的新样本比例低于设定阈值 α 时停止迭代。

最大的收获就是告诉了我0.35B的模型依然能从更多的数据中获得7%的提升。
